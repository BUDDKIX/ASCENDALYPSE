# ASCENDALYPSE

A pixel-art spring platformer set in an abandoned robotics facility. The current release contains Floor 0: the Overcharge prologue, Maker fight and flooded climb to the lift. More floors are planned.

Open `project.godot` in Godot 4.7.2 and press F5. Use the Web preset to export `index.html` for browser play. See `projects description.txt` for controls and progress.
